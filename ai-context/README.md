# Zero to a Billion — ai-context

Read this right after `../AGENTS.md`, every session. This folder is the project's
portable context: how the AI works here, what this project is, and what's
next. It's a map, not the content. The game itself is described in `../docs/`,
routed by `../CLAUDE.md`.

## Onboarded?

Yes. This project was restructured into the Agent OS on 2026-10-19, six milestones in.
The game docs were already complete, so there is no `onboarding.md` and no
`docs/specs/` folder: the docs in `../docs/` are the specs.

## Read order

| Situation | Read this |
|---|---|
| Before any task | `operation-manual.md` |
| What is this project | `5w.md` |
| What to do next | `next-steps.md`, then `/step` |
| Where the whole project is up to | `roadmap.md` (milestones, deadline, ticks) |
| A rule for the task pipeline | `pipeline.md`, **one section by heading**, never whole |
| Why was X decided / has this bug happened before | `python scripts/gate.py search "<words>"` |
| Where is feature X | `python scripts/gate.py where X` |
| A game fact | `../CLAUDE.md` > One fact, one home |

## Files

```
ai-context/
├── README.md             ← catalog, you are here
├── operation-manual.md   ← fixed role, Hard Stops, communication rules (always read)
├── pipeline.md           ← the 7-stage task pipeline (read by section)
├── 5w.md                 ← who / what / when / where / why, in pointers
├── next-steps.md         ← live priority list (overwritten in place, max 40 lines)
├── roadmap.md            ← master checklist: milestones, dates, ticks (generated)
└── roadmap.json          ← the same, for dashboards (generated)
```

## Maintenance

- `operation-manual.md` and `pipeline.md` are copies of masters in the
  project-context-architect skill. Change the master, then run the skill's
  `scaffold.py --sync`. Never edit the copies here.
- `next-steps.md` is overwritten after every verified step. `5w.md` changes only
  through a confirmed re-scope. History goes to the CHANGELOG.
- `roadmap.md` and `roadmap.json` are generated by `gate.py`. Never edit them;
  change the plan with `/roadmap`.
- Sizes are capped by `python scripts/gate.py budget`: this file 60 lines,
  `next-steps.md` 40, `5w.md` 80.
